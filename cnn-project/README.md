# CNN Project - Brain Diseases Classification

This repository contains a deep learning project for medical imaging classification of neurological diseases using convolutional neural networks.

## Contents
- `src/`: source code for data loading, model definitions, training utilities, inference, and helpers
- `config/`: JSON configuration files for datasets and training parameters
- `train.ipynb`, `train_alzheimer.ipynb`, `train_stroke.ipynb`: Jupyter notebooks for training and experimentation
- `results/`: output folder for model artifacts, plots, metrics, and confusion matrices (ignored in Git)
- `data/`: dataset directory (ignored in Git)
- `models/`: trained model weights and checkpoints (ignored in Git)

## Notes
- Datasets, weights, results, and environment artifacts are excluded from version control
- Only source code, configuration, notebooks, and documentation are kept in the repository

## Getting Started
1. Create and activate a Python environment
2. Install dependencies
3. Run notebooks or `train.py` with the appropriate configuration
